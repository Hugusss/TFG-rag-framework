# ADR-012 — matplotlib as an optional extra for the required plots

Increment: plots

## Problem

The result figures must be regenerable by command from the saved raw
results, with labelled axes, experiment identifiers, a sequential /
collective distinction and percentile ranges — a figure nobody can
rebuild is not evidence. The project's dependency rule is stdlib first,
and the standard library cannot draw.

## Options

(a) **matplotlib**, declared as an optional extra (`plots`), imported
only by `benchmarks/plot_results.py`.
(b) matplotlib as a runtime dependency of the framework.
(c) A lighter plotting library, or emitting SVG by hand from the
stdlib.
(d) Plot outside the repository (spreadsheet, notebook).

## Decision

**(a)**: `pip install -e ".[plots]"`; `matplotlib>=3.9,<4`; the
framework package never imports it; the script fails with a one-line
instruction if it is missing; the test module skips cleanly without it.

## Reasons

- The framework's runtime footprint does not change: ingest, query and
  benchmarks run without the extra; only figure regeneration needs it.
- matplotlib is the conventional, headless-capable (`Agg`) choice with
  a stable API; hand-written SVG (c) would be more code than the eight
  plots themselves and would not earn the reader's trust.
- (d) would mean figures built from manually entered summary values;
  they must instead be reproducible by command from committed JSON and
  stamped with their source file and git commit.

## Consequences

- `figures/*.png` are derived artifacts, regenerated by
  `python benchmarks/plot_results.py` and committed (small) so the
  handover and the thesis draw from one source; editing a PNG by hand
  is never allowed — change the results or the script.
- The script takes one result file per kind; a missing kind is an
  error, never a placeholder figure, and so is an ambiguous one. When
  a kind has several committed campaigns the run must be named with
  `--pin`: choosing the newest silently would let a later campaign at
  another scale redraw a figure whose caption still describes the old
  one. The guide records the exact command for the committed set.
